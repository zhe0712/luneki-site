01開始使用

第一次打開 Luneki 時，會問你主要想修哪種照片（風景・夜景・星空／人像・自拍／都有），我們會把常用的工具排在前面。所有功能都能使用，之後可以在「設定 → 常用工具排序」更改。

  1. 點「選擇照片」從相簿挑照片，或用「匯入 RAW 檔」直接打開相機 RAW。
  2. 也可以按相機圖示在 App 內拍照，拍完直接進入編輯。
  3. 加入的照片會出現在下方的縮圖列，點一下就能切換；已調整過的照片會有標記，切換時不會重新計算。
小技巧

相簿裡的原始照片永遠不會被修改，刪除 App 內的照片也不會影響相簿。

02認識編輯畫面

畫面上方是照片，下方是工具選盤與目前工具的控制面板。

  1. 工具選盤依分類排列：設定集、基礎、一鍵、風景、濾鏡、人像、身形。點上方的分類標籤可以快速跳過去。
  2. 點任何工具，它就會加入成一個「調整項目」，下方出現滑桿。
  3. 長按照片，或按右上角的眼睛圖示，可以暫時看原圖對比。
  4. 雙指縮放可以放大檢查細節；放大時會即時重算可視範圍，看到的是全解析度。按「全圖」一鍵回到整張。
  5. 右上角的全螢幕按鈕可以收起所有面板，只看照片。
  6. 復原、重做在工具列上；「複製」「貼上」可以把整組編輯套到另一張照片。
小技巧

雙擊雙向滑桿（中間為 0 的那種）可以一鍵歸零。

03調整項目與非破壞性編輯

Luneki 的每一個編輯都是獨立的「調整項目」，像圖層一樣疊在照片上。

  1. 點上方的「調整項目」可以看到目前加入的所有調整。
  2. 每個調整都能隨時再點進去修改、停用（暫時關掉看差別）或刪除。
  3. 同一種工具可以加入多次，例如兩個局部調整分別處理天空與地面。
小技巧

因為不會破壞原圖，你可以放心大膽地調，隨時回頭改。

04星空與夜景

夜景與星空照片最常見的問題是雜訊、光害與層次不足。建議的順序：

  1. AI 降噪：先清掉高 ISO 雜訊。強度太高會讓細節變軟，星空建議 40–70。
  2. 暗部細節：用「去霧」撥開光害與薄霧，「清晰度」拉出銀河的結構，「陰影／亮部」找回暗部與高光。
  3. 基礎調整：拉一點對比，色溫往冷調讓夜空回到深藍。
  4. 鏡頭：加上星芒，讓城市燈光變成 6–18 道的光芒；邊暈可以把視線集中到中央。
小技巧

白天的霧霾用「AI 去霧」效果最好；暗部細節裡的去霧比較適合夜景與星空。

煙火照被煙蓋住時，用暗部細節裡的「去煙」：大片的煙會被扣掉、火花保留。完全不透明的整團濃煙沒辦法還原，只會變暗；整片均勻的霧則用「去霧」。

05多張疊圖（煙火、星空、HDR）

把多張照片合成一張，可以降噪、留下煙火軌跡或擴大動態範圍。

  1. 點上方的「圖層」，再點加入照片，選擇同一場景連拍的多張照片。
  2. 在「疊圖方式」選擇模式：煙火（保留每一張最亮的部分）、星空（平均降噪）、HDR（融合不同曝光並去除鬼影）。
  3. 按「對齊」：星空模式會對齊星點，其他模式對齊畫面。想回到未對齊的狀態可以按「還原對齊」。
  4. 每一層都能設定遮罩，例如「自動天空」只疊天空、地景保持清晰。
  5. 完成後選「合成結果」，就能用所有工具繼續調整合成圖。
小技巧

用腳架拍攝效果最好；星空建議 4 張以上，間隔越短星點越不會拖影。

下次可以用「重開上次疊圖」接著編輯。

疊完的煙火照如果煙很重，在合成結果上加「暗部細節 → 去煙」就能一起清掉。建議用腳架、同一機位連拍。

06天空調整

天空工具會先辨識天空，只對天空作用。

  1. 在「遮罩方式」選擇：自動（用深度推估，範圍較寬）或精準（語意分割，貼合建築與樹木邊緣）。
  2. 用滑桿套用效果：增藍、晚霞（紫紅漸層）、火燒雲（橘紅）、加雲、立體感、通透，或用「改色」與「色相」直接改變天空顏色。
  3. 開啟「顯示遮罩」可以看到辨識範圍；用筆刷加入或擦掉，修正邊緣。
小技巧

「邊緣過渡」選平滑，可以蓋住樹葉之間細小的殘縫。

07局部調整與遮罩

只想調亮主體、壓暗天空？用局部調整建立遮罩，再套用曝光、對比、色溫等調整。

  1. 在「選區」選擇天空、主體、人物、背景或地面，或點照片上的任何物件直接選取（可以點多個）。
  2. 切換到「筆刷」可以手動加入或用橡皮擦去掉區域，筆刷大小可調。
  3. 開啟「顯示遮罩」確認範圍，再調整下方的滑桿。
小技巧

加入多個局部調整，就能讓天空、地面、人物各自有不同的設定。

08曲線、HSL 與濾鏡

需要精準控色時：

  1. 曲線：調整整體或紅、綠、藍單一通道；點開全螢幕編輯器可以更精細地拉控制點。
  2. HSL：分別調整八種顏色的色相、飽和與明度，例如只讓天空更藍、膚色更通透。
  3. 濾鏡：16 種風格，強度可調，可以疊在其他調整之上。

09人像：修膚、美肌與臉型

人像工具會自動偵測臉部與身體。合照時，可以先選要調整哪一個人。

  1. 深層修膚：AI 去除瑕疵、保留毛孔與質感，是修膚的首選。
  2. 美肌：自動修瑕、去皺紋、去黑眼圈、美白、牙齒美白、膚色冷暖與深淺。
  3. 去斑修痘：點一下臉上的斑點或痘痘就會修掉，可以復原上一點或全部清除。
  4. 臉部重塑：臉頰、眼睛大小、鼻子大小、下巴、額頭、臉寬、嘴型、雙下巴等，沿著真實輪廓調整。
  5. 身形：身形、小腹、腿長、大腿、手臂、肩寬、臀寬等，畫面外的部位不會被亂變形。
小技巧

註冊常拍的人（PRO），之後的照片會自動認出他，詢問是否套用他專屬的設定。

10化妝與換髮色

化妝工具共有 22 個部位，每個部位都有濃淡滑桿與色票。

  1. 最快的方式：在設定集選「淡妝」「濃妝」「韓系珠光」「日系甜美」等妝容。
  2. 再進入化妝調整個別部位：粉底、修容、鼻影、高光、眉毛、眼影、亮粉、眼線、睫毛、假睫毛、臥蠶、腮紅、口紅、水光唇、水光肌、美瞳等。
  3. 「整體濃度」一次調整全部部位的濃淡。
  4. 換髮色會辨識頭髮並保留髮絲明暗，選色票即可。

11背景虛化與散景光斑

模擬大光圈鏡頭的淺景深。

  1. 加入「背景虛化」，App 會自動找出人物並保持清晰；也可以點選或刷出要保留清晰的人。
  2. 「光圈」控制模糊程度，「焦點」與「邊緣」調整清晰範圍與過渡。
  3. 開啟「散景光斑」，背景的燈光會變成圓形光斑；可調光斑大小、柔和度、光圈形狀，以及邊緣的貓眼效果。
小技巧

夜晚有燈光的背景，散景光斑的效果最漂亮。

12畫筆

在照片上自由繪圖或寫字，畫的內容也是一個獨立的調整項目，可以隨時停用或刪除。

  1. 在濾鏡類別加入「畫筆」。
  2. 選顏色（10 種色票，或點最右邊的色盤自訂），調整粗細與不透明度。
  3. 用手指或 Apple Pencil 在照片上畫；切換到「橡皮擦」只會擦掉畫的內容，不會擦到照片。
  4. 「復原上一筆」可以一筆一筆撤回，「清除全部」可以重來。
小技巧

筆畫依原圖解析度重新繪製，輸出全解析度時線條仍然清晰。

畫筆會疊在所有調整之上，之後再瘦臉或調色也不會把畫的內容拉歪。

13物件消除

移除路人、雜物、電線或任何不想要的東西。

  1. 加入「物件消除」，用筆刷塗掉要移除的物件。
  2. 放開手指後 AI 會自動補上背景。
  3. 小斑點用「去斑修痘」點一下更快。
小技巧

塗的範圍略大於物件本身，填補會更自然。

14設定集與批次

把喜歡的調整存起來，下次一鍵套用。

  1. 內建設定集分成人像、妝容與風景（夜晚、晨昏、陽光、星空等）。
  2. 調好一張照片後，在設定集「存成設定集」即可保存（免費版最多 3 組，PRO 無限）。
  3. 在縮圖列按「管理」→ 選取多張照片，可以一次貼上編輯或輸出選取的照片（批次輸出為 PRO）。

15輸出

按右上角的「輸出」，選擇輸出選項後存到相簿。

  1. 格式：JPEG、HEIC、PNG 或 TIFF；可選 16 位元色深與畫質。
  2. 大小：原始解析度或 720p、1080p、1440p、4K（免費版最高 1080p）。
  3. 可選擇保留 EXIF 與色彩描述檔。
  4. 浮水印位置與大小可調；PRO 可以關閉浮水印。
小技巧

批次輸出時請停留在畫面上、不要鎖定螢幕，直到全部完成。

16iPad 與 Apple Pencil

在 iPad 上，Luneki 會改用左右分欄：左邊是大畫布，右邊是工具與滑桿。

  1. 橫向或 13 吋直向會自動切換成分欄；分割畫面或較窄時則維持一般版面。
  2. 用 Apple Pencil 畫過一次後，筆刷與畫筆只回應 Pencil，手指改為移動與縮放，不會誤畫。
  3. 支援懸停的 Apple Pencil 靠近螢幕時，會顯示筆刷範圍的圓圈。
  4. 畫筆會依 Pencil 的力道改變粗細。這個行為可以在「設定 → 只用 Apple Pencil 繪圖」中關閉。
