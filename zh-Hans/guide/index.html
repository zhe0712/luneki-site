01开始使用

第一次打开 Luneki 时，会问你主要想修哪种照片（风景・夜景・星空／人像・自拍／都有），我们会把常用工具排在前面。所有功能都可以使用，之后可以在「设置 → 常用工具排序」中更改。

  1. 点「选择照片」从相册挑选照片，或用「导入 RAW 文件」直接打开相机 RAW。
  2. 也可以点相机图标在 App 内拍照，拍完直接进入编辑。
  3. 加入的照片会出现在下方的缩略图栏，点一下即可切换；调整过的照片会有标记，切换时不会重新计算。
小技巧

相册里的原始照片永远不会被修改，删除 App 内的照片也不会影响相册。

02认识编辑界面

界面上方是照片，下方是工具面板与当前工具的控制面板。

  1. 工具面板按分类排列：预设、基础、一键、风景、滤镜、人像、身形。点上方的分类标签可以快速跳转。
  2. 点任意工具，它就会作为一个「调整项目」加入，下方出现滑块。
  3. 长按照片，或点右上角的眼睛图标，可以临时查看原图对比。
  4. 双指缩放可以放大检查细节；放大时会实时重算可视范围，看到的是全分辨率。点「全图」一键回到整张照片。
  5. 右上角的全屏按钮可以收起所有面板，只看照片。
  6. 撤销、重做在工具栏上；「复制」「粘贴」可以把整组编辑套用到另一张照片。
小技巧

双击双向滑块（中间为 0 的那种）可以一键归零。

03调整项目与非破坏性编辑

Luneki 的每一项编辑都是独立的「调整项目」，像图层一样叠在照片上。

  1. 点上方的「调整项目」可以看到当前加入的所有调整。
  2. 每项调整都能随时再点进去修改、停用（暂时关闭看差别）或删除。
  3. 同一种工具可以加入多次，例如用两个局部调整分别处理天空与地面。
小技巧

因为不会破坏原图，你可以放心大胆地调，随时回头修改。

04星空与夜景

夜景与星空照片最常见的问题是噪点、光污染与层次不足。建议的顺序：

  1. AI 降噪：先清除高 ISO 噪点。强度太高会让细节变软，星空建议 40–70。
  2. 暗部细节：用「去雾」拨开光污染与薄雾，「清晰度」拉出银河结构，「暗部／高光」找回暗部与高光。
  3. 基础调整：加一点对比，色温调冷，让夜空回到深蓝。
  4. 镜头：加上星芒，让城市灯光变成 4、6 或 8 道光芒；边晕可以把视线集中到画面中央。
小技巧

白天的雾霾用「AI 去雾」效果最好；暗部细节里的去雾更适合夜景与星空。

烟花照被烟盖住时，用暗部细节里的「去烟」：大片的烟会被扣掉、火花保留。完全不透明的整团浓烟无法还原，只会变暗；整片均匀的雾则用「去雾」。

05多张叠图（烟火、星空、HDR）

把多张照片合成一张，可以降噪、留下烟火轨迹或扩展动态范围。

  1. 点上方的「图层」，再添加照片，选择同一场景连拍的多张照片。
  2. 在「叠图方式」中选择模式：烟火（保留每一张最亮的部分）、星空（平均降噪）、HDR（融合不同曝光并去除鬼影）。
  3. 点「对齐」：星空模式会对齐星点，其他模式对齐画面。想回到未对齐的状态可以点「还原对齐」。
  4. 每一层都能设置遮罩，例如用「自动天空」只叠天空，地景保持清晰。
  5. 完成后选「合成结果」，就能用所有工具继续调整合成图。
小技巧

使用三脚架拍摄效果最好；星空建议 4 张以上，间隔越短星点越不会拖影。

下次可以用「重开上次叠图」继续编辑。

叠完的烟花照如果烟很重，在合成结果上加「暗部细节 → 去烟」就能一起清掉。建议用脚架、同一机位连拍。

06天空调整

天空工具会先识别天空，只对天空起作用。

  1. 选择识别模式：自动（用深度估算，范围较宽）或精准（语义分割，贴合建筑与树木边缘）。
  2. 用滑块应用效果：增蓝、晚霞（紫红渐变）、火烧云（橙红）、加云、立体感、通透，或直接改变天空的色相。
  3. 打开「显示遮罩」可以看到识别范围；用笔刷添加或擦除，修正边缘。
小技巧

边缘过渡选「平滑」可以盖住树叶之间细小的缝隙。

07局部调整与遮罩

只想提亮主体、压暗天空？用局部调整建立遮罩，再应用曝光、对比、色温等调整。

  1. 在「选区」中选择天空、主体、人物、背景，或点照片上的任意物体直接选取（可以点选多个）。
  2. 切换到「笔刷」可以手动添加区域，或用橡皮擦去掉区域，笔刷大小可调。
  3. 打开「显示遮罩」确认范围，再调整下方的滑块。
小技巧

加入多个局部调整，就能让天空、地面、人物各自拥有不同的设置。

08曲线、HSL 与滤镜

需要精准控色时：

  1. 曲线：调整整体或红、绿、蓝单一通道；打开全屏编辑器可以更精细地拖动控制点。
  2. HSL：分别调整八种颜色的色相、饱和与明度，例如只让天空更蓝、肤色更通透。
  3. 滤镜：16 种风格，强度可调，可以叠加在其他调整之上。

09人像：修肤、美肌与脸型

人像工具会自动检测脸部与身体。合照时，可以先选择要调整哪一个人。

  1. 深层修肤：AI 去除瑕疵，保留毛孔与质感，是修肤的首选。
  2. 美肌：自动修瑕、去皱纹、去黑眼圈、美白、牙齿美白、肤色冷暖与肤色深浅。
  3. 祛斑祛痘：点一下脸上的斑点或痘痘就会修掉，可以「撤销上一处」或「清除全部」。
  4. 脸部重塑：脸颊、眼睛大小、鼻子大小、下巴、额头、脸宽、嘴型、双下巴等，沿真实轮廓调整。
  5. 身形：身形、小腹、腿长、大腿、手臂、肩宽、臀宽等，画面外的部位不会被乱变形。
小技巧

注册常拍的人（PRO），之后的照片会自动认出他，并询问是否应用他专属的设置。

10化妆与换发色

化妆工具共有 22 个部位，每个部位都有浓度滑块与色板。

  1. 最快的方式：在预设中选择「淡妆」「浓妆」「韩系珠光」「日系甜美」等妆容。
  2. 再进入化妆调整各个部位：粉底、修容、鼻影、高光、眉毛、眼影、亮粉、眼线、睫毛、卧蚕、腮红、口红、水光唇、水光肌等。
  3. 「整体浓度」可一次调整所有部位的浓淡。
  4. 换发色会识别头发并保留发丝明暗，选择色板即可。

11背景虚化与散景光斑

模拟大光圈镜头的浅景深。

  1. 加入「背景虚化」，App 会自动找出人物并保持清晰；也可以点选或刷出要保持清晰的人。
  2. 「光圈」控制模糊程度，「焦点」与「边缘」调整清晰范围与过渡。
  3. 打开「散景光斑」，背景灯光会变成圆形光斑；可调光斑大小、光斑柔和度、光圈形状，以及边缘的口径蚀（猫眼）效果。
小技巧

夜晚有灯光的背景，散景光斑的效果最漂亮。

12画笔

在照片上自由绘图或写字，画的内容也是一个独立的调整项目，可以随时停用或删除。

  1. 在滤镜类别中添加「画笔」。
  2. 选颜色（10 种色票，或点最右边的色盘自定义），调整粗细与不透明度。
  3. 用手指或 Apple Pencil 在照片上画；切换到「橡皮擦」只会擦掉画的内容，不会擦到照片。
  4. 「撤销上一笔」可以一笔一笔撤回，「清除全部」可以重来。
小技巧

笔画按原图分辨率重新绘制，导出全分辨率时线条依然清晰。

画笔会叠在所有调整之上，之后再瘦脸或调色也不会把画的内容拉歪。

13物体消除

移除路人、杂物、电线或任何不想要的东西。

  1. 加入「物体消除」，用笔刷涂抹要移除的物体。
  2. 松开手指后，AI 会自动补全背景。
  3. 小斑点用「祛斑祛痘」点一下更快。
小技巧

涂抹范围略大于物体本身，补全会更自然。

14预设与批量处理

把喜欢的调整保存起来，下次一键套用。

  1. 内置预设分为人像、妆容与风景（夜晚、晨昏、阳光、星空等）。
  2. 调好一张照片后，在预设中点「存为预设」即可保存（免费版最多 3 组，PRO 无限）。
  3. 在缩略图栏点「管理」→ 选取多张照片，可以一次粘贴编辑或导出所选照片（批量导出为 PRO 功能）。

15导出

点右上角的「导出」，选择导出选项后保存到相册。

  1. 格式：JPEG、HEIC、PNG 或 TIFF；可选 16 位深色与画质。
  2. 导出大小：原始分辨率或 720p、1080p、1440p、4K（免费版最高 1080p）。
  3. 可选择保留 EXIF 与色彩描述文件。
  4. 水印位置与大小可调；PRO 可以关闭水印。
小技巧

批量导出时请停留在当前界面、不要锁屏，直到全部完成。

16iPad 与 Apple Pencil

在 iPad 上，Luneki 会改用左右分栏：左边是大画布，右边是工具与滑块。

  1. 横屏或 13 英寸竖屏会自动切换成分栏；分屏浏览或窗口较窄时则保持一般布局。
  2. 用 Apple Pencil 画过一次后，笔刷与画笔只响应 Pencil，手指改为移动与缩放，不会误画。
  3. 支持悬停的 Apple Pencil 靠近屏幕时，会显示笔刷范围的圆圈。
  4. 画笔会按 Pencil 的力度改变粗细。这个行为可以在「设置 → 仅用 Apple Pencil 绘图」中关闭。
