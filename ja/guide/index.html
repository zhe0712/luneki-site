01はじめに

Luneki を初めて開くと、主にどんな写真を編集するか（風景・夜景・星空／人物・自撮り／両方）を尋ね、よく使うツールを前に並べます。すべての機能はいつでも使え、あとから「設定 → ツールの並び順」で変更できます。

  1. 「写真を選択」でライブラリから写真を選ぶか、「RAWを読み込む」でカメラの RAW ファイルを直接開きます。
  2. 追加した写真は画面下のサムネイル列に表示され、タップで切り替えられます。調整済みの写真には印が付き、切り替えても再計算されません。
ヒント

ライブラリの元写真が変更されることはなく、アプリ内で写真を削除してもライブラリには影響しません。

不具合やほしい機能があれば、「設定 → ヘルプとサポート → 不具合の報告・機能のご要望」から直接メールでお知らせください。アプリのバージョンと機種は自動で添付されます。

02編集画面の見かた

画面上部に写真、下部にツールパレットと現在のツールの操作パネルがあります。

  1. ツールパレットはカテゴリ別に並んでいます：プリセット、基本、ワンタップ、風景、フィルター、ポートレート、体型。上部のカテゴリタブをタップするとすばやく移動できます。
  2. ツールをタップすると「調整項目」として追加され、下にスライダーが表示されます。
  3. 写真を長押しするか、右上の目のアイコンをタップすると、一時的に元画像と比較できます。
  4. ピンチで拡大して細部を確認できます。拡大中は表示範囲をリアルタイムに再計算し、フル解像度で表示します。「全体」をタップすると写真全体の表示に戻ります。
  5. 右上の全画面ボタンですべてのパネルを隠し、写真だけを表示できます。
  6. 元に戻す・やり直すはツールバーにあります。「コピー」「貼り付け」で編集内容をまるごと別の写真に適用できます。
ヒント

両方向スライダー（中央が 0 のもの）はダブルタップで 0 に戻せます。

03クイック：よく使う調整をワンタップで

よく使う調整をボタンにまとめました。写真をさっと仕上げたいときにぴったりです。

  1. ツールパレットのいちばん左にある「クイック」をタップすると、ポートレートと風景のよく使うボタンが表示されます。最上段は「最近使用」です。
  2. ボタンをタップすると小さなウィンドウが開き、その項目のスライダーだけが表示されます。メイク系は関連するパーツと色もまとめて表示されます。たとえば「アイシャドウ」には、上まぶた、「ラメ」、「下まぶたシャドウ」、「目尻シャドウ」が含まれます。
  3. 複数のボタンを同時に使って重ねがけできます。適用中のボタンはオレンジ色で表示されます。
  4. ウィンドウ右上のスイッチで、その項目を一時的にオフにできます。数値は記憶されていて、オンに戻すと元どおりになります。
ヒント

クイックと通常のツールは同じ数値を調整しているので、どちらで変更しても同期されます。

04調整項目と非破壊編集

Luneki の編集は一つひとつが独立した「調整項目」で、レイヤーのように写真に重なっていきます。

  1. 上部の「調整項目」をタップすると、追加したすべての調整を確認できます。
  2. どの調整もいつでも開き直して、変更、無効化（一時的にオフにして比較）、削除ができます。
  3. 同じツールを何度でも追加できます。たとえば部分調整を 2 つ使って、空と地面を別々に調整できます。
  4. リスト右上の「すべて元に戻す」で、この写真のすべての調整と切り抜きを消去して元画像に戻せます。「元に戻す」をタップすれば取り戻せます。
ヒント

元画像は一切変更されないので、思い切って調整して、いつでもやり直せます。

05星空と夜景

夜景や星空の写真でよくある悩みは、ノイズ、光害、階調不足です。おすすめの順番：

  1. AIノイズ除去：まず高感度ノイズを取り除きます。強すぎると細部が甘くなるので、星空なら 40～70 がおすすめです。
  2. シャドウ詳細：「かすみ除去」で光害や薄いかすみを晴らし、「明瞭度」で天の川の構造を引き出し、「シャドウ／ハイライト」で暗部と明部を取り戻します。
  3. 基本：コントラストを少し上げ、色温度を下げて夜空を深い青に戻します。
  4. レンズ：光条を加えて街の灯りを 6–18 本の光の筋に。周辺減光で視線を中央に集めることもできます。
ヒント

日中のかすみには「AIかすみ除去」が最も効果的です。シャドウ詳細のかすみ除去は夜景や星空に向いています。

花火が煙に覆われたら、シャドウディテールの「煙除去」を。広い煙は差し引かれ、火花は残ります。完全に不透明な煙の塊は復元できず暗くなるだけです。全体に均一なかすみには「かすみ除去」を使います。

06多枚数合成（花火・星空・HDR）

複数の写真を 1 枚に合成して、ノイズを減らしたり、花火の軌跡を残したり、ダイナミックレンジを広げたりできます。

  1. 上部の「レイヤー」をタップし、写真を追加して、同じシーンを連写した複数の写真を選びます。
  2. 「重ね方」でモードを選びます：花火（各写真の最も明るい部分を残す）、星空（平均してノイズを低減）、HDR（異なる露出を融合し、ゴーストを除去）。
  3. 写真を追加したときや星空・HDR モードに切り替えたとき、レイヤーがまだ揃っていなければ、位置合わせするかどうかをアプリが尋ねます。「位置合わせ」はいつでもタップできます。星空モードは星を追跡して、HDR は画面全体を合わせます。位置合わせ前に戻したいときは「位置合わせを戻す」をタップします。
  4. 各レイヤーにはマスクを設定できます。たとえば「自動空」なら空だけを合成し、地上の風景はくっきりのまま保てます。
  5. 完成したら「合成結果」を選ぶと、すべてのツールで合成画像をさらに調整できます。
ヒント

三脚を使うと最もきれいに仕上がります。星空は 4 枚以上がおすすめで、撮影間隔が短いほど星が流れにくくなります。

次回は「前回の合成を開く」で続きから編集できます。

合成した花火写真の煙が濃いときは、結果に「シャドウディテール → 煙除去」を加えましょう。三脚で同じ位置から撮るのがおすすめです。

07空の調整

空ツールはまず空を認識し、空だけに効果をかけます。

  1. マスクの方式を選びます：自動（深度から推定し、範囲は広め）または高精度（セマンティックセグメンテーションで、建物や木の輪郭にぴったり沿う）。
  2. スライダーで効果をかけます：青空、夕焼け（紫～赤のグラデーション）、焼け雲（オレンジ～赤）、雲を追加、立体感、透明感。空の色相を直接変えることもできます。
  3. 「マスク表示」をオンにすると認識範囲を確認できます。ブラシで追加・消去して輪郭を整えましょう。
ヒント

エッジを「なめらか」にすると、葉の間の細かなすき間も埋められます。

08部分調整とマスク

被写体だけ明るくしたい、空だけ暗くしたい——そんなときは部分調整でマスクを作り、露出、コントラスト、色温度などを調整します。

  1. 「範囲」で空、被写体、人物、背景を選ぶか、写真上のオブジェクトをタップして直接選択します（複数選択も可能）。
  2. 「ブラシ」に切り替えると、手作業で範囲を追加したり、消しゴムで消したりできます。ブラシのサイズも調整可能です。
  3. 「マスク表示」をオンにして範囲を確認してから、下のスライダーを調整します。
ヒント

部分調整を複数追加すれば、空、地面、人物にそれぞれ別の設定をかけられます。

09トーンカーブ・HSL・フィルター

色を細かくコントロールしたいときは：

  1. トーンカーブ：全体、または赤・緑・青の各チャンネルを個別に調整します。全画面エディタを開けば、コントロールポイントをさらに細かく動かせます。
  2. HSL：8 色それぞれの色相・彩度・輝度を個別に調整します。空だけをより青く、肌をより透明感のある色に、といった調整が可能です。
  3. フィルター：16 種類のスタイルを強さを調整して適用でき、他の調整の上に重ねられます。

10ポートレート：美肌・肌補正・輪郭

ポートレートツールは顔と体を自動で検出します。グループ写真では、まず調整する人を選べます。

  1. ディープ美肌：AI が毛穴や質感を残したまま肌トラブルを除去します。肌補正はまずここから。
  2. 美肌ケア：自動シミ除去、シワ除去、クマ除去、美白、歯のホワイトニング、肌色（暖/寒）、肌色（明/暗）。
  3. シミ・ニキビ：顔のシミやニキビをタップするだけで消せます。「1つ戻す」や「すべてクリア」も使えます。
  4. 輪郭調整：頬、目の大きさ、鼻の大きさ、あご、額、顔の幅、口、二重あごなどを、実際の輪郭に沿って調整します。
  5. 体型：体型、お腹、脚の長さ、太もも、腕、肩幅、ヒップなど。フレームの外にある部位が不自然にゆがむことはありません。
ヒント

よく撮る人を登録すると（PRO）、以降の写真でその人を自動で認識し、専用の設定を適用するか確認します。

11メイクと髪色チェンジ

メイクツールは 22 パーツに対応し、パーツごとに濃さのスライダーとカラーパレットがあります。

  1. いちばん手軽なのは、プリセットから「ナチュラルメイク」「しっかりメイク」「韓国風パール」「日系スイート」などのメイクを選ぶ方法です。
  2. さらにメイクを開いて、パーツごとに調整します：ファンデ、シェーディング、ノーズシャドウ、ハイライト、眉、アイシャドウ、ラメ、アイライナー、マスカラ、涙袋、チーク、口紅、リップグロス、ツヤ肌など。
  3. 「全体の濃さ」ですべてのパーツの濃さを一度に調整できます。
  4. 髪色チェンジは髪を認識し、毛束の明暗を残したまま色を変えます。カラーを選ぶだけです。

12背景ぼかしと玉ボケ

大口径レンズの浅い被写界深度を再現します。

  1. 「背景ぼかし」を追加すると、アプリが人物を自動で見つけてくっきり保ちます。くっきり残したい人をタップやブラシで指定することもできます。
  2. 「絞り」でぼけの量を、「フォーカス」と「エッジ」でピントの合う範囲と境目のなじみを調整します。
  3. 「玉ボケ」をオンにすると、背景の灯りが玉ボケに変わります。「玉ボケの明るさ」で明るさを、「玉ボケサイズ」と「玉ボケの柔らかさ」で見た目を調整します。形状は円形・六角・八角のほか、ハート・星・きらめき・花といった遊び心のある形も選べ、画面周辺の口径食(猫目)効果も加えられます。
ヒント

灯りのある夜の背景では、玉ボケがいちばん美しく映えます。

13ペン

写真に自由に絵や文字を描けます。描いた内容はひとつの独立した調整項目なので、いつでもオフにしたり削除したりできます。

  1. フィルターカテゴリから「ペン」を追加します。
  2. 色を選び（10 色のカラースウォッチ、または右端のカラーホイールで自由に指定）、太さと不透明度を調整します。
  3. 指または Apple Pencil で写真に描きます。「消しゴム」に切り替えると描いた内容だけを消し、写真そのものは消しません。
  4. 「1画戻す」で 1 画ずつ取り消し、「すべてクリア」で最初からやり直せます。
ヒント

ストロークは元画像の解像度で描き直されるので、フル解像度で書き出しても線はくっきりしたままです。

ペンはすべての調整の上に重なるため、あとで小顔補正や色調整をしても描いた内容がゆがみません。

14オブジェクト除去

通行人、余計な物、電線など、写したくないものを消せます。

  1. 「オブジェクト除去」を追加し、消したいものをブラシで塗ります。
  2. 指を離すと、AI が背景を自動で補完します。
  3. 小さな点なら「シミ・ニキビ」でタップするほうが速いです。
ヒント

対象より少し広めに塗ると、より自然に補完されます。

15プリセットと一括処理

お気に入りの調整を保存して、次回はワンタップで適用できます。

  1. 内蔵プリセットはポートレート、メイク、風景（夜、朝夕、晴れ、星空など）に分かれています。
  2. 写真を仕上げたら、プリセットの「プリセットを保存」で保存できます（無料版は 3 件まで、PRO は無制限）。
  3. サムネイル列で「管理」→ 複数の写真を選択すると、編集をまとめて貼り付けたり、選択した写真を書き出したりできます（一括書き出しは PRO）。
  4. 「管理」画面では、追加日・最終編集・撮影日で並べ替えたり、撮影日・編集日・カメラ・レンズ・ファイル形式でグループ分けしたりできます。左上の「⋯」から「未編集の写真を削除」や「すべて削除」も行えます。

16書き出し

右上の「書き出し」をタップし、保存先と書き出しオプションを選びます。

  1. 保存先：「写真」または「ファイル」。「ファイル」を選ぶと、iCloud Drive や外部ストレージ、ほかのアプリのフォルダに保存できます。一括書き出しではすべて同じフォルダに保存されます。
  2. 形式：JPEG、HEIC、PNG、TIFF。16ビットの色深度と画質も選べます。
  3. サイズ：オリジナルの解像度、または 720p、1080p、1440p、4K（無料版は最大 1080p）。
  4. EXIF とカラープロファイルを保持するかどうかを選べます。
  5. 透かしの位置とサイズは調整可能。PRO なら透かしをオフにできます。
  6. 書き出しが終わったら、「表示」で拡大して原寸の細部を確認したり（一括の場合は左右にスワイプ）、「共有」でそのまま友だちに送ったりできます。
ヒント

一括書き出し中はこの画面のままにしておくのがおすすめです。ほかのアプリに切り替えると写真と写真の間で一時停止し、Luneki に戻ると自動で再開します。

17iPad と Apple Pencil

iPad では、Luneki は左右分割のレイアウトに切り替わります。左に大きなキャンバス、右にツールとスライダーが並びます。

  1. 横向き、および 13 インチ iPad の縦向きでは自動的に分割レイアウトになります。Split View や幅の狭いウインドウでは通常のレイアウトのままです。
  2. Apple Pencil で一度描くと、ブラシとペンは Pencil にだけ反応し、指は移動と拡大縮小に使われるので、誤って描いてしまうことがありません。
  3. ホバー対応の Apple Pencil では、画面に触れる前にブラシの範囲が円で表示されます。
  4. ペンは Pencil の筆圧で太さが変わります。この動作は「設定 → Apple Pencil のみで描く」でオフにできます。
